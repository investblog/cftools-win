# Cloudflare Tools — Store Listing (Italiano / it)

## Description

Nessun software aggiuntivo richiesto: il runtime .NET 8 e il Windows App SDK sono inclusi nel pacchetto (self-contained).

Tools for Cloudflare porta la gestione massiva delle zone, rapida e affidabile, sul desktop Windows. Pensata per i professionisti dei domini che gestiscono decine o centinaia di zone su più account Cloudflare. Funziona con il tuo account Cloudflare tramite l'API pubblica Cloudflare v4.

• Aggiunta domini in blocco — incolla domini da qualsiasi fonte: elenchi, CSV, HTML, e-mail, URL o esportazioni. Il parser estrae i domini radice, gestisce IDN e Punycode, segnala i duplicati e ti lascia controllare l'elenco prima di creare qualcosa.
• Elenco zone ed esportazione CSV — ogni zona con stato, piano e name server; filtra per nome ed esporta in CSV, per un account o per tutti gli account insieme.
• Svuotamento cache in blocco — seleziona le zone, avvia lo svuotamento e segui l'avanzamento zona per zona.
• Eliminazione zone in blocco — filtra, seleziona, conferma in una finestra di sicurezza, segui lo stato di ogni zona; l'elenco si ricarica al termine.
• Esportazione dei risultati — dopo ogni aggiunta, svuotamento o eliminazione, salva un CSV con stato e testo dell'errore per dominio.
• Token API o Global API Key — accedi con un token utente (cfut_), un token dell'account (cfat_) o la chiave classica; il tipo viene riconosciuto dal segreto incollato.
• Più account — accedi una volta e cambia account senza reinserire le credenziali.
• Tema scuro e chiaro — secondo Windows o a scelta.
• Parla 12 lingue (italiano, inglese, russo, tedesco, francese, spagnolo, portoghese, giapponese, coreano, cinese, polacco, turco) e segue la lingua di Windows.

Le credenziali restano in Gestione credenziali di Windows e vengono inviate solo all'API Cloudflare. Nessuna telemetria, nessuna analisi, nessun acquisto. Codice sorgente su GitHub.

Disponibile anche come estensione «Cloudflare Tools» per Chrome, Edge e Firefox. Creata da 301.st, una piattaforma di gestione dei redirect edge.
