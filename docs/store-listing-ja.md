# Cloudflare Tools — Store Listing (日本語 / ja)

## Description

Cloudflare® は Cloudflare, Inc. の登録商標です。Cloudflare Tools は 301.st が開発する独立したオープンソースアプリで、Cloudflare, Inc. とは提携・承認・後援のいずれの関係もありません。公開されている Cloudflare API v4 を通じて、ご自身の Cloudflare アカウントを操作します。

アプリのインターフェースは英語です。

Cloudflare Tools は、高速で信頼できるゾーンの一括管理を Windows デスクトップにもたらします。複数の Cloudflare アカウントで数十〜数百のゾーンを扱うドメイン担当者のためのツールです。

• ドメインの一括追加 — リスト、CSV、HTML、メール、URL、エクスポートなど、どんな形式のテキストでも貼り付けるだけ。パーサーがルートドメインを抽出し、IDN と Punycode に対応、重複を検出し、作成前にリストを確認できます。
• ゾーン一覧と CSV エクスポート — 全ゾーンのステータス、プラン、ネームサーバーを表示。名前で絞り込み、1 アカウントまたは全アカウントをまとめて CSV に出力。
• キャッシュの一括削除 — ゾーンを選んで一括パージ。ゾーンごとの進捗を表示。
• ゾーンの一括削除 — 絞り込み、選択、確認ダイアログ、ゾーンごとのステータス表示。完了後にリストを自動更新。
• 結果のエクスポート — 追加・パージ・削除の実行後、ドメインごとのステータスとエラー内容を CSV に保存。
• API トークンまたは Global API Key — ユーザートークン(cfut_)、アカウントトークン(cfat_)、従来のキーのいずれでもサインイン可能。貼り付けたシークレットから種類を自動判別。
• 複数アカウント — 一度サインインすれば、認証情報を再入力せずにアカウントを切り替え。
• ダーク/ライトテーマ — Windows の設定に追従、または手動で選択。

認証情報は Windows 資格情報マネージャーに保存され、Cloudflare API にのみ送信されます。テレメトリー、分析、課金は一切ありません。ソースコードは GitHub で公開。

同名のブラウザ拡張機能(Chrome、Edge、Firefox)もあります。開発はエッジリダイレクト管理プラットフォーム 301.st。

## Product features (keyword-first, ≤200 chars each)

1. Cloudflare へのドメイン一括追加:リスト、CSV、HTML、URL を貼り付け — ルートドメイン抽出、IDN/Punycode 対応、重複検出、作成前の事前チェック
2. ステータス・プラン・ネームサーバー付きのゾーン一覧 — 名前で絞り込み、1 アカウントまたは全アカウントを CSV にエクスポート
3. 選択したゾーンのキャッシュ一括削除 — ゾーンごとの進捗表示とキャンセル
4. 確認ダイアログ付きのゾーン一括削除 — ゾーンごとのステータス表示と自動再読み込み
5. バッチ結果を CSV に出力:ドメイン、ステータス、エラー — 記録や再実行に
6. API トークン(cfut_ / cfat_)または Global API Key でサインイン、種類は自動判別。シークレットは Windows 資格情報マネージャーに保存
7. 複数アカウント:一度のサインインで、再入力なしに Cloudflare アカウントを切り替え
8. レート制限を考慮した要求キュー(再試行とバックオフ付き)。ダーク/ライトテーマ。オープンソース、テレメトリーなし
