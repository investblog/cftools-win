# Cloudflare Tools — Store Listing (Русский / ru)

## Description

Cloudflare Tools — быстрое и надёжное массовое управление зонами Cloudflare прямо на рабочем столе Windows. Для специалистов, которые ведут десятки и сотни зон в нескольких аккаунтах Cloudflare. Работает с вашим собственным аккаунтом Cloudflare через публичный Cloudflare API v4.

• Массовое добавление доменов — вставьте домены из любого источника: списки, CSV, HTML, письма, URL или экспорты. Парсер извлекает корневые домены, поддерживает IDN и Punycode, отмечает дубликаты и даёт проверить список до создания.
• Список зон и экспорт в CSV — все зоны со статусом, тарифом и NS-серверами; фильтр по имени и экспорт в CSV для одного аккаунта или для всех сразу.
• Массовая очистка кеша — выберите зоны, запустите пакетную очистку и следите за прогрессом по каждой зоне.
• Массовое удаление зон — фильтр, выбор, подтверждение в диалоге безопасности, статус по каждой зоне; список обновляется после завершения.
• Экспорт результатов — после любого добавления, очистки или удаления сохраните CSV со статусом и текстом ошибки по каждому домену.
• API-токен или Global API Key — вход с пользовательским токеном (cfut_), токеном аккаунта (cfat_) или классическим ключом; тип определяется по вставленному секрету.
• Несколько аккаунтов — войдите один раз и переключайтесь без повторного ввода данных.
• Тёмная и светлая тема — по настройкам Windows или вручную.
• Говорит на 12 языках (русский, английский, немецкий, французский, испанский, итальянский, португальский, японский, корейский, китайский, польский, турецкий) и следует языку Windows.

Учётные данные хранятся в Windows Credential Manager и передаются только в Cloudflare API. Без телеметрии, аналитики и покупок. Исходный код на GitHub.

Также доступно как расширение для Chrome, Edge и Firefox под тем же именем. Разработано 301.st — платформой управления редиректами на edge.

1. Массовое добавление доменов в Cloudflare: вставьте список, CSV, HTML или URL — корневые домены извлекаются, IDN и Punycode поддерживаются, дубликаты отмечаются, проверка до создания
