# Bulk Zone Manager 1.2.3

**Where to get it**

- [Microsoft Store](https://apps.microsoft.com/detail/9pn4wf799808) — the only distribution channel; installs and updates automatically.
- This release is **source-only**: the standalone installer was retired (see "Why" below).

**Changes**

- About page: removed the "Source code on GitHub" link and the Edge/Chrome/Firefox browser-extension links in all 12 languages. The only remaining links are "Rate this app in Microsoft Store" and the publisher's site (301.st, a web service with no software download).
- Downloadable installers were removed from all previous GitHub releases; the Store is now the only way to get the app.
- `scripts/make_cert_token.py` (maintainer tooling): creates the scoped Cloudflare demo token submitted with the Store certification notes.

**Why**

Microsoft Store policy 10.1.5 (Software Distribution) forbids a Store product from promoting software acquired outside the Store. Certification report `cea3f4fc-7445-4e34-9b28-f3dfcbb0aecf` (2026-11-18) flagged the About page links, which led to this repository's installer downloads. Full story: `docs/store-appeal-2026-10.md`.

**Product name**

The Windows app is "Bulk Zone Manager" (Microsoft Store naming policy 10.1.1.1: a referential product must not start with the referenced service's name); the browser extension keeps the name Cloudflare Tools.
