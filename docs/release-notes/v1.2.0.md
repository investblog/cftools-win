## Cloudflare Tools 1.2.0

**Which file to download**

- `CloudflareTools-v1.2.0-x64-setup.exe` — installer for Windows 10/11 x64. Self-contained: no .NET runtime to install.
- `CloudflareTools-v1.2.0-x64.zip` — the same app without an installer; unzip anywhere and run `CFTools.exe`.
- `SHA256SUMS` — checksums of both; verify with `sha256sum -c SHA256SUMS` (Git Bash) or `certutil -hashfile <file> SHA256`.
- Prefer a store? [Microsoft Store](https://apps.microsoft.com/detail/9pn4wf799808) installs and updates it for you.

The installer and the ZIP are not code-signed yet, so SmartScreen may ask you to confirm the first run.

**What's new**

- **Zones page** — every zone with status, plan and nameservers; filter by name; export to CSV for one account or for all accounts at once.
- **API tokens** — sign in with a user token (`cfut_`) or an account-owned token (`cfat_`) alongside the Global API Key; the kind is detected from the pasted secret.
- **Export batch results** — after any add, purge or delete run, save a CSV with per-domain status and error text.
- **12 languages** — English, Russian, German, French, Spanish, Italian, Portuguese (Brazil), Japanese, Korean, Chinese (Simplified), Polish, Turkish; follows the Windows display language, overridable in Settings.
- **About** — Rate this app, links to the browser extensions and the source code, trademark notice.
- **301.st tips** — short, dismissible hints after creating zones and while zones are pending; switch them off in Settings.

**Fixes**

- Token verification no longer fails on Cloudflare's `messages[]` objects.
- Account list is paginated, so accounts beyond the first page are no longer dropped.
- Per-zone status text and status badges update reliably, including after a theme change.
- Cancelling a batch records the never-started items as cancelled and keeps the progress counters honest.
- Delete no longer resets its freshly reloaded list after a successful batch.
- InfoBar backgrounds match the active theme at startup and after switching themes.
